1. make sure python and java are installed

2. Download Haddop we will be using hadoop 3.5 (latest 2026 Apr2 )

    cd ~
    wget https://archive.apache.org/dist/hadoop/common/hadoop-3.5.0/hadoop-3.5.0.tar.gz
    tar -xzf hadoop-3.5.0.tar.gz
    mv hadoop-3.5.0 hadoop

OR

    #https://www.apache.org/dyn/closer.lua/hadoop/common/hadoop-3.5.0/hadoop-3.5.0.tar.gz
extract to home/

3. we need to setup hadoop to be reconized. We can see if we running
    wner@Owner:~$ hadoop version
    hadoop: command not found

#point haddop at java
    echo 'export JAVA_HOME=$(dirname $(dirname $(readlink -f $(which java))))' >> ~/.bashrc

#set hadoops home
    echo 'export HADOOP_HOME=$HOME/hadoop' >> ~/.bashrc

#add hadoop to path
    echo 'export PATH=$PATH:$HADOOP_HOME/bin:$HADOOP_HOME/sbin' >> ~/.bashrc

#reload bash (or repoen wsl)
    source ~/.bashrc

We need to edit haddops env files for the jobs to run
    nano $HOME/hadoop/etc/hadoop/hadoop-env.sh
    add : export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 
    anywhere near the top

6. Open the folder CONMP455-GroupProject/hadoopwsl in the windows file explored. right click on a empty space and click
open in terminal.   Type "wsl" into it. This will open the folder in wsl

The shell is now in the hadoopwsl directory we can now run the haddop job:

    rm -rf /tmp/hadoop-out
   "$HOME/comp455-venv/bin/python" ingester.py > /tmp/trips.csv
   hadoop jar $HOME/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.5.0.jar \
     -files mapper.py,reducer.py,tracker.py \
     -mapper "/usr/bin/python3 mapper.py" \
     -reducer "/usr/bin/python3 reducer.py" \
     -cmdenv MAPPER_ENCODE=True \
     -input /tmp/trips.csv \
     -output /tmp/hadoop-out
   cat /tmp/hadoop-out/part-*

This times it (just using linux time) and saves the output results

rm -rf /tmp/hadoop-out
/usr/bin/time -f "elapsed_seconds %e" -o /tmp/hadoop-time.txt \
  hadoop jar $HOME/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.5.0.jar \
    -files mapper.py,reducer.py,tracker.py \
    -mapper "/usr/bin/python3 mapper.py" \
    -reducer "/usr/bin/python3 reducer.py" \
    -cmdenv MAPPER_ENCODE=True \
    -input /tmp/trips.csv \
    -output /tmp/hadoop-out \
  2>&1 | tee /tmp/hadoop-console.txt
cp /tmp/hadoop-console.txt /tmp/hadoop-time.txt /tmp/hadoop-out/
